# User flows

## 1. Find and join a run (≤ 2 taps)
Home → “Runs near you” → **Join · N spots** (inline) → row switches to “You're in”. Or: Courts → pick a court → “Runs here” → run → Join.

## 2. Call a run (≤ 3 taps with defaults)
Create a run → (closest court and next half-hour already set) → adjust format/target/type → **Call it** → run page with share code. In demo mode, fictional nearby players join every ~1.6 s until full.
Validation: time in the past, > 60 days out, ranked with extra spots, house rules > 120 chars.

## 3. Game Loop
1. **Check in** — type the code (must match) or Scan QR (simulated). Shows “You're checked in” with your QR for others.
2. **Teams** — formed when enough players check in; balanced by MMR (snake draft); host taps to swap.
3. **Tip off** → full-screen “Phone down. Go hoop.” with a timer and nothing else.
4. **Game over** → final score. Rules: no ties; winner ≥ target; above target must be win-by-2.
5. **Your box score** — steppers for PTS/AST/REB/STL/BLK/TO; points can't exceed team score.
6. **Evidence** — all lines by team with Σ vs final. Mismatch banner (no blame) → *Ask {teammate} to recheck* (they revise) or *Lower my points*. Confirm/Dispute other lines. *Request confirmations* → your line climbs the ladder. *Save to My Game* (blocked while mismatched).
7. **Reflection** (notification also arrives) → chips → optional prompts → result: DNA deltas with reasons + top insight with evidence and confidence.

## 4. Player identity
My Game → Customize player → tabs Jersey / Look / Gear / Skill FX → Save (validates nickname, number, contrasting colors). Share card → preview + copy link.

## 5. Community
Players (filter by city, free now, archetype) → profile sheet (MMR, Trust, DNA, invite to your run, report, block). Squads → Join/Leave. Rankings → region. Challenges → Accept (if addressed to you or your squad).

## 6. Opportunities
Filter type / city / window / 18+ → detail sheet (organizer verification banner, details) → optional “share my card” consent → I'm interested → withdraw anytime.

## 7. Court data stewardship
Court detail → Submit correction (≥ 8 chars) → pending. Add a court → name, type, hoops, landmark → pending, shown under “Your submissions”.
